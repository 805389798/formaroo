**正文**:

```
I got tired of building form handlers for every side project. Contact forms, waitlists, feedback widgets — always the same boilerplate: a server, a database, CORS handling, spam filtering.

So I built Formaroo: point your <form> action at an endpoint, and submissions are stored, spam-filtered and forwarded automatically.

<form action="https://formaroo.yearn05.top/f/YOUR_FORM_ID" method="POST">
  <input name="email" type="email" required>
  <button type="submit">Subscribe</button>
</form>

That's it. No server, no database, no CORS setup.

What it does:
• Stores submissions (dashboard included)
• Spam protection out of the box (honeypot + rate limiting + Turnstile on auth)
• Webhook forwarding to your own server
• Redirect after submit (thanks page)
• JSON API for JS-based forms

Pricing: free tier (100/month) → $9 Pro (10k/month) → $29 Scale (100k/month).
Try it live: https://formaroo.yearn05.top

Tech: Next.js 16 on Cloudflare Workers (OpenNext), Supabase, Gumroad for payments.

Would love feedback on the workflow — especially from people who've used Formspree/Basin and know what's missing.
```
